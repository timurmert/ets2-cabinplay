CabinPlay - a working media screen for your truck cabin (Euro Truck Simulator 2)
Made by HydRaboN.            Turkce: BENIOKU.txt

This zip is for installing by hand. The easier way is the setup on the same download
page, CabinPlay-Setup-x.y.z.exe: it finds the game by itself and installs everything.

BY HAND (close the game first)
  1. Copy cabinplay.scs into
        Documents\Euro Truck Simulator 2\mod
  2. Copy cabinplay.dll and cabinplay.ini from the plugin folder into the game's
        bin\win_x64\plugins
     folder. Create the "plugins" folder if it is not there.
     To find the game folder: in Steam, right-click the game > Manage > Browse local files.
  3. Copy the app folder anywhere you like (for example Documents\CabinPlay)
     and start CabinPlay.exe in it once. From then on it starts with the game by itself.

THEN, IN THE GAME
  1. Start the game and accept the "SDK features" notice it shows once.
  2. In the Mod Manager, switch on "CabinPlay Screen".
  3. In a truck workshop, fit "CabinPlay Screen" in a windscreen accessory slot: on the
     left (Large or Compact) or in the middle (Centre). The workshop has more places too,
     and "CabinPlay TV" to watch from the bunk.

USE
  Ctrl+Alt+C      use the screen from inside the game with mouse and keyboard (Esc to leave)
  Ctrl+Alt+N      navigation map          Ctrl+Alt+H   home screen
  Ctrl+Alt+Space  play / pause            Ctrl+Alt+F   video fullscreen
  Ctrl+Alt+PgUp / PgDn  previous / next open app
  Ctrl+Alt+S      two apps side by side   Ctrl+Alt+X   swap the two sides
  Settings: your own background picture, other shortcut keys, and steering-wheel or
  gamepad buttons for any shortcut.
  The Mirrors app shows the truck's own mirrors on the screen.
  The Browser app opens any website; type the address in control mode.
  Closed CabinPlay from its settings? Ctrl+Alt+C starts it again.
  The Truck app shows the damage to the truck and trailer, the cargo and the fuel.
  The shortcuts also work while the game is in front; their keys never reach the game.
  The language and all shortcuts are under Settings on the screen.

NEEDS
  Euro Truck Simulator 2 1.61, Windows 10 or 11. No DLC is needed.
  Single player only: it does not work with TruckersMP.

REMOVE
  Delete the files you copied. If you used the setup instead, open Windows
  Settings > Apps > CabinPlay > Uninstall.
