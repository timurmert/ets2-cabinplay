CabinPlay - a working media screen for your truck cabin (Euro Truck Simulator 2)
Made by HydRaboN.            Turkce: BENIOKU.txt

Close the game first. Then install it one of two ways.

A) AUTOMATIC
  Double-click Install.cmd.
  If Windows says it protected your PC, click "More info", then "Run anyway".
  Install.cmd only starts data\install.ps1, a plain text script you can open and read.

B) BY HAND (no script is run)
  1. Copy data\cabinplay.scs into
        Documents\Euro Truck Simulator 2\mod
  2. Copy cabinplay.dll and cabinplay.ini from data\plugin into the game's
        bin\win_x64\plugins
     folder. Create the "plugins" folder if it is not there.
     To find the game folder: in Steam, right-click the game > Manage > Browse local files.
  3. Copy the data\app folder anywhere you like (for example Documents\CabinPlay)
     and start CabinPlay.exe in it once. From then on it starts with the game by itself.

THEN, IN THE GAME
  1. Start the game and accept the "SDK features" notice it shows once.
  2. In the Mod Manager, switch on "CabinPlay Screen".
  3. In a truck workshop, fit "CabinPlay Screen" in the left windscreen accessory slot
     (Large or Compact).

USE
  Ctrl+Alt+C      use the screen from inside the game with mouse and keyboard (Esc to leave)
  Ctrl+Alt+N      navigation map          Ctrl+Alt+H   home screen
  Ctrl+Alt+Space  play / pause            Ctrl+Alt+F   video fullscreen
  The language and all shortcuts are under Settings on the screen.

NEEDS
  Euro Truck Simulator 2 1.61, Windows 10 or 11, the Cabin Accessories DLC.
  Single player only: it does not work with TruckersMP.

HELP
  Join our Discord: https://discord.gg/rhGEbsu3zy
  To report a problem, open Settings on the screen, press "Create error report" and
  post the zip it saves.

REMOVE
  Double-click Uninstall.cmd, or delete the files you copied in B).
